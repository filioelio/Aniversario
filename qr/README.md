# Carpeta `qr/`

Esta carpeta es solo un lugar sugerido para guardar la imagen del código QR
que generes con `qr-generator.html` (ubicado en la raíz del proyecto).

## Pasos

1. Publica tu sitio en GitHub Pages (ver el `README.md` principal).
2. Copia la URL que te da GitHub Pages, por ejemplo:
   `https://usuario.github.io/aniversario/`
3. Abre `qr-generator.html` en tu navegador (puede ser localmente, haciendo
   doble clic en el archivo).
4. Pega la URL, presiona **Generar QR ❤️** y luego **Guardar QR como imagen**.
5. Si quieres, guarda la imagen descargada dentro de esta carpeta (`qr/`)
   para tenerla ordenada junto al proyecto. Esto es opcional: el QR no
   necesita estar en el repositorio para funcionar.
6. Comparte esa imagen (impresa, por WhatsApp, etc.) con tu pareja.

`qr-generator.html` es una herramienta solo para ti; no forma parte de la
experiencia que verá la otra persona.
